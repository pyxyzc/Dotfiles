# 搜索性能验收（2026-09-22）

本机 Vim 9.1、fzf 0.44.1、GNU awk 5.2.1、本地磁盘。端到端测试通过真实 PTY
发送快捷键、查询、回车及编辑按键；Vim 通过本地 socket 报告界面状态，避免计时器
写日志和同步刷盘污染结果。正常文件保留实际安装的 clangd。

`fr` 切换已有候选项到新预览：中位数 5.27 ms，P95 6.51 ms。
各入口首次显示界面分别为 89.37、22.39、22.27 ms；首次 ff 包含依赖查找和能力检测。

热启动 ≤50 ms、回车到可编辑 ≤50 ms 的 P95 目标通过；ff/fr 的结果和预览目标通过。
**fp 的查询刷新 ≤100 ms 目标尚未通过**，当前约 204–209 ms；这是完整交互测量结果。

已安装配置另做 2 MiB 文件测试（每种模式首次加 3 次热测量），回车到编辑生效

## 瓶颈对照

以下每组独立运行 3 次，取中位数。原版本取自本次修改前的 Git HEAD。

| 场景 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 30 万条匹配的完整处理 | 9642.82 ms | 609.61 ms |
| 30 万行文件预览 | 116.75 ms | 4.56 ms |
| 2.4 万行嵌套 C++ 的打开、跳转及重绘 | 1101.74 ms | 2.67 ms |

预览改为最多 64 KiB / 200 行的局部内容，C++ 默认改为手动折叠；以上两项包含
已确认的功能取舍。完整匹配结果继续流式提供，不截断候选总数。

另复现并修复了退出时偶发约 5 秒的等待：子进程已退出、通道已关闭，但 close_cb
仍未到达。现在在退出后检查通道状态，确认关闭并耗尽缓冲后，再延迟到下一轮事件
循环清理。60 次连续 fr 打开复测未再出现该等待，并有屏蔽 close_cb 的独立回归测试。

## 复测

在 Dotfiles 根目录运行：

```bash
python3 vim/tests/search_latency.py --rounds 30
python3 vim/tests/search_latency.py --config /root/.vimrc --rounds 3 --files 100 --size 2097152
python3 vim/tests/search_latency.py --mode fr --rounds 60 --profile /tmp/vim-search.profile
```

`--no-lsp` 可用于单独排查语言服务器开销；验收表中的正常文件数据启用了 LSP。
回归覆盖特殊文件名、UTF-8/UTF-16、超长行、256 MiB 深处的预览、取消及重开、
旧查询子进程清理、延迟关闭回调、分屏回退、安装、大文件 LSP 隔离和配置重载。

最终检查：82 项 Vim 回归通过；LSP 为 8 项通过、1 项既有预期失败；样式、Shell
语法及 `git diff --check` 通过。完整测试发现另有 6 项 tmux 安装器测试失败，原因是
该安装脚本与测试的选项约定不一致；本次未改动 tmux 模块。
