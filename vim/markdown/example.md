# 把想法，写成文档

在 Vim 中专注写作，在 TokyoNight 中舒适阅读。
**清晰的结构**、*流畅的表达*，以及随时可见的预览。

> [!TIP]
> 按 `Space m p` 打开实时预览。未保存的内容也会自动更新。
> 按 `Space m f` 进入专注模式，`Space m o` 打开标题目录。

## 写作清单

- [x] 让标题层级一目了然
- [x] 延续 TokyoNight 的蓝紫色调
- [ ] 给下一个想法留些空间
- [-] 正在整理下一章的素材
- [!] 等待一份关键资料

在列表末尾按 **Enter** 继续下一项；空项再按一次即可结束列表。
把光标放在任务行，按 `Space m x` 勾选或取消。

## 一段代码，一个思路

<!--
作者备注：这段注释在原生阅读视图中隐藏，源码和插入模式可查看。
注释和显示用的边框始终保持为原始文件内容，阅读视图不会改写文档。
-->

```python
def write_something(idea: str) -> str:
    """先记录，再整理。"""
    return f"# {idea}\n\n从这里开始。"

print(write_something("今天的灵感"))
```

未知语言保留原始代码，常见语言会自动高亮。代码块右上角可以复制。

## 用表格组织信息

| 操作 | 快捷键 | 作用 |
| :--- | :---: | --- |
| 实时预览 | `Space m p` | 跟随 Vim 光标 |
| 阅读视图 | `Space m r` | 切换可视化与源码 |
| 表格对齐 | `Space m t` | 按中文显示宽度整理 |
| 插入模板 | `Space m i` | 代码块、表格、链接与公式 |
